# 好感知识页重构设计

## 目标

把“好感知识”做成玩家查数值和规则的速查页。首屏先给出最常用答案，完整等级数据和来源说明放入展开区；页面不承担目标规划、库存编辑或礼包计算。

## 页面结构

1. 顶部速查区：1→100、99→100、金色礼物最高值三个结果卡片。
2. 礼物价值区：普通礼物和金色礼物按小/中/大/特大展示，并使用现有礼物图标作视觉锚点。
3. 日常来源区：咖啡厅摸头和日程的数值，明确“已实装学生可计入；未实装或未知学生只按礼物”。
4. 完整等级表：默认折叠，保留每一级的下一级需求和累计好感。
5. 数据说明：默认折叠，仅保留快照来源和等级上限。

## 交互与边界

- 不新增独立计算器，规划计算继续由养成规划页负责。
- 所有数值来自现有 `relationship_thresholds.json`；缺失值显示“—”。
- 中英日使用同一结构和对应翻译。
- 桌面端使用宽内容区，窄屏端所有卡片单列，不能横向溢出。

## 验收标准

- 首屏能直接看到 1→100 和 99→100 的好感值。
- 玩家能一眼区分普通礼物、金色礼物、日常来源。
- 完整等级表和来源说明不占首屏空间，但仍可展开查看。
- 页面不再出现大片空白或只有“数据说明”的泛化文案。
- 现有知识页单元测试、全量测试和浏览器控制台检查通过。
